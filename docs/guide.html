How to run the platform

From a cold start to waves on the platform. Follow the sections in order the first time. Lines in dark boxes are what the program prints, so you can check each step worked.

Measurements sheet
Keep your hand near the driver power switches

The program stops the legs on the limit switches and has speed limits, but it is not a safety circuit. The only true emergency stop is switching off driver power. Clear people and loose objects from the platform and from under it.

1Before you power up

Tick each of these with the power off.

  • The platform sits on a firm, level surface. Outdoors, shield the laptop screen from sun and keep cables off the ground where legs can reach them.
  • Each crank can swing through its full range without touching a link, a cable or the frame.
  • The three drivers are set to 2000 pulses per revolution. With the 10:1 gearboxes, 20 000 steps are one turn of a crank.
  • Each driver’s PUL− and DIR− go to a Nucleo ground. Signals follow this table.
  • Each limit switch is wired normally closed: common to ground, the other contact to its pin. A broken wire then looks the same as a pressed switch, and the program stops.
  • Each switch is positioned so its crank presses it at the bottom of travel, and nothing else can reach it.
  • Driver power is off. The Nucleo is connected to the computer with a USB cable that carries data (not a charge-only cable).

2Load the firmware

Skip this section if the board already runs the latest program and you only want to use it.

  1. Open the project Test2 in STM32CubeIDE.

  2. From the repository, copy every file in firmware/Core/Inc into the project’s Core/Inc and every file in firmware/Core/Src into Core/Src. Say yes to replace main.c and main.h.

  3. Edit Core/Inc/plat_config.h if you have measured the geometry (Measure page, button Show plat_config.h lines). Without it the program still works, but mm and degree values are estimates and the menu says geometry NOT SET.

  4. Choose Project → Build Project. If the linker complains about sinf or sqrtf, open Properties → C/C++ Build → Settings → MCU GCC Linker → Libraries and add m, then build again.

  5. Press Run (the green button). If CubeIDE asks about a debug configuration, accept the defaults. The board resets and starts the program.

If you ever regenerate code from the .ioc file

Check MX_GPIO_Init in main.c afterwards. The three limit inputs must be GPIO_PULLUP. Regenerated code can set them to no pull and the switches will read wrongly.

3Connect to the board

Only one program can use the board’s serial port at a time. Use PuTTY or the control panel, and close the one before opening the other.

Option A: PuTTY

  1. Find the port. In Windows open Device Manager → Ports (COM & LPT) and note the number beside STMicroelectronics STLink Virtual COM Port, for example COM5.

  2. In PuTTY choose Connection type: Serial. Serial line: your COM number. Speed: 115200. Under Connection → Serial check 8 data bits, 1 stop bit, parity none, flow control none.

  3. Click Open, then press the black RESET button on the Nucleo. You should see:

    Sea platform firmware ready.
Status: not homed | calibration: saved in flash | geometry: set | telemetry: off
...
=========== SEA PLATFORM ===========
 1  Setup: home, set minimums, set maximum, save
 ...
Select:

    Nothing appears? Press Enter once, then check the COM number and that the USB cable carries data.

Option B: the browser control panel

  1. Open the control panel in desktop Chrome or Edge. It must be the published HTTPS site or localhost.

  2. Press Connect and choose STLink Virtual COM Port. The panel shows the same messages as PuTTY in its log, with buttons for each mode and a box to type keys.

Then switch on driver power

With the menu showing, switch on the three drivers. Doing it in this order means the board is already holding its outputs in a known state when the drivers wake up.

4First run: home the legs and set the limits

You do this once, then the values are saved in the board’s flash and kept after a power cycle. Repeat it if you move a limit switch or change a crank.

4a. Home

  1. At the menu press 1 (Setup). The program reads the three switches:

    Switches: X released  Y released  Z released

Clear the area and keep a hand near the driver power switches.
Press any key to start homing (q = cancel)...

    If a switch says PRESSED while its crank is away from it, the program warns you and waits for y to continue or q to cancel. Cancel and check the wiring: a pressed reading with the crank away usually means the wire is broken or on the wrong pin.

  2. Press any key. First all three legs come down together, in small alternating bursts, so no leg is ever far ahead of the others, however high the platform started. When a leg reaches its switch it stops and waits for the others. Then each leg in turn backs off 500 steps and approaches the switch slowly to latch the exact position:

    Lowering all three legs together to their switches...
X is on its switch.
Y is on its switch.
Z is on its switch.
Homing X...
X homed OK.
Homing Y...
Y homed OK.
Homing Z...
Z homed OK.

All legs homed. Moving to the minimum positions...
Ready.

    If a leg moves away from its switch, or does not stop, press q or switch off driver power, then check HOME_DIR_LEGn in plat_config.h and the DIR wiring.

  3. The Setup menu appears:

    === SETUP ===
 1  set MINIMUMS (jog each leg until the platform is level)
 2  set MAXIMUM (jog all three legs together)
 3  motion limits (speed, acceleration)

 5  LEG DIFFERENCE limit (largest difference between two legs)
 s  SAVE to flash      d  restore defaults (not saved)      h  re-home      q  back
Select:

4b. Set the minimums, one leg at a time

The minimum is the lowest position where the platform is level. All three legs share one level height, so this fixes the rest position.

  1. Press 1. Put a spirit level or phone level app on the platform.

  2. Use u / j to raise or lower all three legs together until the platform is near the height you want as its bottom position. Press + for a bigger step (fast) or - for a smaller step (fine).

  3. Select one leg with x, y or z, then nudge it with d (up) and a (down) until the platform is level. Repeat for the other legs. The readout shows the selected leg’s letter, the three step counts, and the size of one jog step:

    [Z] X=1034 Y=1038 Z=1042 | step 0.50 deg (28 steps)

  4. When level, press n to mark all three legs’ minimums here (or m to mark only the selected leg). Press p to print what is stored:

    Minimums: X=1034 Y=1038 Z=1042   Maximums: X=8567 Y=8595 Z=8693

    These numbers are an example. Yours will differ.

  5. g sends the legs back to the saved minimums so you can check they come back level. Press q when done.

In this screen x, y and z choose a leg. They do not stop the platform.

Emergency stop x works in the modes, not while you are setting minimums. To stop here, switch off driver power.

This is also the moment to measure the geometry. Stay at the level minimum and follow the measurements sheet.

4c. Set the maximum

  1. Press 2. The legs first go back to the saved minimums so they rise together from level.

  2. Raise all three together with u. Go in small steps near the top. Stop before a crank is nearly straight up or down, the link nearly touches anything, or the motors sound strained.

  3. Press m to mark the maximum. If it says Too close to the minimums – raise the platform first, raise it further. g returns to the minimums, q finishes.

4d. Find the largest pitch and roll (safety limits)

The program only knows the geometry you typed in. You know where the links would touch the frame or each other. Here you tilt the platform by hand and mark the furthest you are willing to go in each of the four directions. Once saved, every mode (manual, circles, waves, MAX) shrinks its motion to stay inside them.

  1. At the Setup menu press 4. The platform rises to the middle of the stroke, level (press q if you want to give up while it moves):

    --- Find the TILT limits by hand ---
Tilt limits: pitch +0.00 / -0.00 deg, roll +0.00 / -0.00 deg   (0.00 = not set)

  2. Tilt it a little at a time: w / s pitch + / − (front X up / down), d / a roll + / − (back-left Z up / down). u / j change the height, + / − change the step size (0.25° to 2°), z levels it again at the same height. Each press prints where it is:

    heave 0.0 mm (0 = mid) | pitch 6.00 deg | roll 0.00 deg

  3. When you reach the furthest you are happy with, let it stop moving, then press p to mark the pitch limit or r to mark the roll limit. Whichever side it is tilted towards is the side that gets marked:

    Pitch limit marked.
Tilt limits: pitch +8.00 / -0.00 deg, roll +0.00 / -0.00 deg   (0.00 = not set)

    Do all four: pitch up, pitch down, roll one way, roll the other. z between them. A side you never mark stays not set and only the geometry limits it.

  4. Tilt it further first (at least 1 degree; it measures 0.00 deg now). means the platform was not tilted enough when you pressed the key, or it was still on its way. l lists the limits, c clears all four, q finishes and levels the platform.

The limits apply at every height

A tilt that is fine in the middle of the stroke may not be fine when the platform is low or high. Try u and j to find the height where it can tilt least, and mark the limit there. The screen warns held by the leg ranges when the geometry stops you before your own limit.

4e. Set the largest difference between two legs

A twisted platform loads the links and the ball joints much more than a level one. This limit is the biggest allowed difference between the heights of two legs, measured in steps above each leg’s own minimum (one step is 0.018° of crank). It is also enforced live: a leg that would get further ahead of the others is held back until they catch up.

  1. At the Setup menu press 5. The legs go to the minimums first (q gives up):

    --- Set the largest DIFFERENCE between two legs ---
[X] heights above the minimums: X=0 Y=0 Z=0 | difference now 0 steps (0.0 deg) | saved limit: not set

  2. Select a leg with x / y / z and raise only that leg with d (a lowers it). u / j move all three; + / − change the step. Stop when the platform is as twisted as you are willing to allow:

    [X] heights above the minimums: X=278 Y=0 Z=0 | difference now 278 steps (5.0 deg) | saved limit: not set

  3. Let it stop, then press m:

    Leg difference limit marked: 278 steps.

    c clears it, g sends the legs back to the minimums, q finishes and returns them there. It needs at least 200 steps to be accepted.

What you will see in use

Modes and the live model shrink their motion to respect it. If the real legs ever drift apart anyway (a leg lagging, a jog key), the engine holds the leading leg and prints Leg difference limit reached: a leg is being held back until the others catch up. It clears itself.

4f. Save

  1. Back at the Setup menu press s:

    Saved to flash. The platform will remember these after a power cycle.

    The save includes the tilt and leg difference limits. Press q to go to the main menu. Leave option 3 (speed and acceleration) at the tested values of 1500 steps/s and 1500 steps/s² unless you have time to experiment.

  2. The status line should now say calibration: saved in flash, and the lines below it show your limits:

    Tilt limits (set by hand): pitch +8.0 / -8.0 deg, roll +8.0 / -6.0 deg  (0.0 = from the geometry only)
Leg difference limit: 278 steps (5.0 deg of crank)

    If it says defaults after you re-flash the board, repeat 4b to 4f. Flash is shared with the program, so a re-flash can sometimes clear it.

5Run the modes

Start gently and work up: 2, then 6, then 3, then 4, then 5. Each mode homes first if it has not yet been homed this session. Inside any mode q returns to the menu (the legs finish what they are doing and settle) and x stops everything at once.

The web panel has a button for every one of these keys, and the live view shows the platform moving. Waves print one line at the start and whenever you change something:

Sea state 3 - slight | wave scale 32% of range (set by amplitude) | time x0.50 | trim 100%

Wave scale is how much of the platform’s range the waves use. Set by tells you what held it back (the range, the speed limit or the acceleration limit). Time x0.50 means the waves play at half speed so the legs can keep up. + and - change the trim.

Wave sizes are shown, not scaled to scale

Sea states 1 and 2 are very small, so heights are shown as Hs 4 × (Hs / Hs 4)0.75 so they stay visible. Say so when presenting. Set WAVE_HS_EXPONENT to 1.0f in plat_config.h for true proportions.

If a leg reaches its limit switch while the program is moving it, the program stops everything and prints:

!!! HOME SWITCH Y FIRED - motion stopped. The platform must be homed again.

That means the position was lost or a limit was set too low. Press h to home again. If it repeats, redo the minimums in Setup.

7Using the control panel and visualiser

  1. Open Control panel in Chrome or Edge, close PuTTY, press Connect.

  2. Pick a mode with its button. The panel sends q first if another mode is running, then the mode key. Go to rest and Re-home are always on screen.

  3. Press Telemetry (or v at the menu) to stream the platform’s heave, pitch and roll. The 3D model and the graphs move with the real legs. Telemetry flows only while a mode is running.

  4. Sending keys. Everything the panel sends goes out one character at a time, in order, about 18 ms apart, so the board never has to catch a burst. STOP (and x in a mode) jumps the queue and cancels whatever is waiting. Tick Send my keystrokes to type straight to the platform: the text box is switched off then, a held key is sent once (only the jog keys u j w s d a repeat, at most 8 a second), and a key never also presses whichever button has the focus. The sliders send only their latest position. In Setup the key buttons follow the screen the platform is on.

  5. The Visualiser page runs the same waves in the browser without the hardware. Use it to show the audience what the platform is about to do, or to try a sea state before running it.

7bPresentation lock and the TV display

Presentation lock

At the main menu press l (or the Lock button in the panel). Setup, Manual and re-home are then refused with LOCKED: not available during the presentation, so a stray key cannot change calibration. Heave cycle, circles, waves, MAX, go to rest, q and x still work. The menu shows PRESENTATION LOCK ON and the TV display shows a yellow LOCKED tag.

To unlock press l again and type UNLOCK then Enter (in the panel, use the text box). Anything else stays locked. The lock is not saved, so a power cycle unlocks it.

TV display

In the control panel press TV display. It goes full screen with the mode (and sea state in Waves and MAX) in large type, LIVE / HOMED / LOCKED tags, heave, pitch and roll as huge numbers, the live 3D model and a 30 second graph. Warnings such as EMERGENCY STOP, HOME SWITCH fired or Leg difference limit reached show as a red banner for 12 seconds. Esc closes it. Telemetry must be on (press Telemetry first). Drag the browser window to the TV and then press the button, since full screen opens on the screen the window is on. Only one page can hold the serial port, so use the TV display from the control panel itself rather than another tab.

8Shut down

  1. Press q until the main menu shows.

  2. Press g and wait for At rest. The legs are now at their lowest level position, which is the safest place to unpower the platform.

  3. Switch off the three drivers.

  4. Close PuTTY or press Disconnect, then unplug the USB cable.

9Run order for the presentation

A suggested order that takes about eight minutes and ends in a safe place. Rehearse it once, end to end, on the actual surface before the audience arrives.

  1. Connect, check the status line says HOMED or home, and that calibration is saved in flash. Show the audience the Visualiser while you explain what the platform does.

  2. 4 Waves. Start with 1 (sea state 1), then 2, 3, 4, about a minute each. Press r for a different random sea.

  3. q, then 5 MAX platform. Press d to show the full-range sweep of heave, pitch and roll.

  4. q, then g. Finish at rest and switch off driver power.

Have a fallback

If the new program misbehaves, the single-file test program in firmware/legacy/main_standalone_tests.c was tested on the rig. Swap it in for main.c.
